## 🔥 Features

### 🏠 Pixoro Feed
- Double tap to love ❤️ with burst animation
- Comment with like/unlike & delete
- Save your favs
- Follow system with counts
- Share anywhere

### 🎬 Pixoro Clips (Vertical)
- Smooth vertical scroll
- Double tap = Heart burst ❤️
- Auto play & pause on scroll
- Tap to pause/play
- Sound on/off 🔊🔇
- Progress indicator
- Comments, likes, save, follow all inside

### 💚 Pixoro Stories
- Super HD 0.95 quality - No blur!
- Public ring (color) & Close Friends ring (green 💚)
- Drag slowly & pinch to zoom
- Long press to manage
- Seen / Unseen logic

### 💬 Pixoro Talks
- Like talks with red heart
- Delete only your talk
- Time & likes count
- Bottom sheet design

### 👤 Pixoro Profile
- Verified badge ✓
- Followers / Following
- Your moments grid
- Saved collection

## 🛠️ Built With

- Backend: Supabase Realtime
- PWA Ready - Installable App
